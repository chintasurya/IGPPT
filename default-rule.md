## Presentations (IGPPT)

When asked to create, make or update a presentation, deck, slides, PPT or PowerPoint, always use the `igppt` skill without being told: write a JSON spec, build it with `igppt/scripts/build_deck.py`, and deliver only after `igppt/scripts/check_deck.py` prints PASS. Never write your own slide code or start from a blank PowerPoint.
